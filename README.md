Réalisation d’une simulation de parking proposant plusieurs modes de jeu :

### [1] Entraînement — Mode facile
L’utilisateur contrôle le véhicule sans risque de collision.

### [2] Entraînement — Mode difficile
L’utilisateur contrôle le véhicule avec gestion des collisions.

### [3] Fluide
Simulation d’un parking avec **5 véhicules automatiques**.

### [4] Chargé
Simulation d’un parking avec **30 véhicules automatiques**.

### [5] Spécial
Simulation d’un parking avec **5 véhicules automatiques** et **1 véhicule contrôlé manuellement**.

## Prérequis - installer la librairie soX :
### MacOS 
```bash
brew install sox
```
### Linux
```bash
sudo apt install sox libsox-fmt-all
```

## Etape pour executer

### 1 - Pour nettoyer :
```bash
make clean
```

### 2 - Pour compiler :
```bash
make
```

### 3 - Lancer le programme compilé :
```bash
make run
```
